Problem

A robot learns whether its plan works only by running it

Vision-language-action models fine-tuned on LIBERO demonstrations reproduce what they memorized and collapse under the position and task perturbations of LIBERO-PRO. Coding agents perceive each new scene and write a program for it, yet they too learn about a plan only from execution: run, look, regenerate. On a robot every such retry can cost a dropped object or a human intervention.

Central question. Can a robot coding agent find out whether its program will work before it runs it, by rehearsing it in a world model learned only from demonstrations?

From trial-and-error execution to rehearsal in imagination. The core innovation is a world model that executes the agent's own code: its high level is conditioned on the code, predicting the latent state after each API call from the call's function name and arguments, and it returns a predicted execution trace that the agent reads and repairs against. Rehearsal recedes with execution, restarting from each real observation, and an uncertainty gate trusts only the calls the model agrees on.

Method

Imagine, repair, then act call by call

The Agentic Policy is a frozen vision-language model (Gemini) that writes Python against a perception and motion API, with retreat after a failed turn, a grasp check in meters, re-observation and re-synthesis; our agent builds on an open-source coding-agent framework. A frozen V-JEPA 2 ViT-L encoder turns the agentview and wrist cameras into tokens, joined by proprioception and force, and a block-causal, action-conditioned predictor rolls them forward at 5 Hz under end-effector delta actions. The four parts below are the Stage 1 design built on these; the planner stays frozen and outside the world model.

01

Code-conditioned hierarchical world model

Each macro step predicts the latent state after one API call from the current latent and an embedding of the call itself: a learned token for the function name, its numeric arguments as values, and the object it acts on, grounded in what the frozen encoder sees (V-JEPA 2 tokens pooled under the mask the agent's own segment_sam3_text_prompt returns, with the text prompt as a second key). The macro level is an ensemble of small heads on a shared trunk; a call is settled only when the heads agree. The micro level stays on the compiled motor actions at 5 Hz and refines the contact calls (close_gripper, open_gripper), every unsettled call and every motion whose path passes near an object. Call labels come free from the demonstrations: replays are cut at gripper events and end-effector stops and labelled by rules on the stored simulator state, with no language-model labels.

02

Scene readout

A small head reads every predicted state: object positions, the object in hand, finger and arm contacts, and which goal conditions hold. It is supervised by the simulator state stored in the demonstration replays (object poses, evaluator contacts, LIBERO's success check) and by the task's goal predicates.

03

Dream API

An imagined backend with the same function signatures, so the agent's program runs unchanged. A rehearsal starts from the latest real observation; each motion or gripper call conditions one macro step; grasp checks and perception calls after an imagined motion answer from the readout, and every call is marked settled or not. During execution, perception reads the real observation. The world model is latent and decodes no pixels.

04

Imagine, Repair, Act

The agent rehearses its program and an accept gate reads the trace: a settled call predicted to fail, or unmet goal conditions, send the program back for repair within a fixed budget. Otherwise the robot executes the next call only; the real observation then replaces the imagined latent and the remaining calls are rehearsed again, so a suffix now predicted to fail is repaired before the next real call, and a call that stays unsettled is executed and read from reality instead of guessed. The recovery loop stays as the fallback after a real failure, and every real retry is counted.

Trained only on LIBERO demonstrations, replayed through the agent's own move primitive with perturbations that supply failures; never on agent episodes. An offline test of an action-level, fixed-stride version found that predicted futures did not beat current-frame features on shifted replays, which is why the model now steps on the agent's calls and reads the scene out.

Evaluation plan

A pre-registered test of rehearsal

LIBERO-PRO in simulation: the Object, Goal and Spatial suites under the Pos and Task perturbations, six cells, at most five episodes per task, paired by task and initial state across rows. The main metric is first-execution completion: the task completed with zero real retries.

Rows R0 and R5 on all six cells; R1 to R4 on one Pos and one Task cell

RowRehearsalAgent reads
R0None (our Agentic Policy without rehearsal)n/a
R1Simulator rehearsal, privileged upper boundfull trace
R2World model, action-level rolloutfull trace
R3World model, code-conditionedsuccess flag
R4World model, code-conditionedfailure event and its call
R5Agentic-LWM: world model, code-conditionedfull trace

Metrics: first-execution completion, final completion, real retries and Gemini calls per episode, rehearsal latency, and per-call agreement between the predicted and the real readout. Suffix repairs during execution are logged apart and do not count as completion at first execution. R1 to R5 share the call-by-call act. The ablation suite is the one with the lowest R0 first-execution completion, fixed after R0 and before any rehearsal run.

Q1 · H1

Does rehearsal make the first execution more reliable under shift?

R5 completes more episodes at first execution than R0. Refuted if the paired interval of the difference contains zero. R1 separates the value of rehearsal from world-model fidelity.

Q2 · H2

Does a world model conditioned on the agent's calls rehearse better than one on motor actions?

On the same programs, code-conditioned rehearsal (R5) beats action-level rehearsal (R2) in first-execution completion and in per-call trace agreement, and the gap grows with the rehearsal horizon. Refuted if either difference or the growth contains zero. At no extra cost, the R5 logs also test that agreement is higher on settled than on unsettled calls and count how often re-anchoring triggers a suffix repair.

Q3 · H3

What must the agent see to fix its code?

At an equal cap on Gemini calls, first-execution completion rises from R3 (flag) to R4 (event and call index) to R5 (full trace). Refuted for each step whose paired interval contains zero.

Stage 2 extends the protocol to LIBERO-MAX, whose scenes change during execution, and to Meta-World MT50 on a second embodiment. The page shows no results; results will be added from run reports.
